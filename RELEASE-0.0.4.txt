dontfeartheripper 0.0.4

Highlights
----------

- Added rollback support
- Added dftr undo command
- Added automatic rename history logging
- Added clearer dry-run output
- Added rename candidate counting

Workflow
--------

Inspect:

    dftr doctor /music

Preview:

    dftr fix /music

Execute:

    dftr fix /music --yes

Rollback:

    dftr undo

Notes
-----

The undo command restores all renames from the most recent successful fix run.
