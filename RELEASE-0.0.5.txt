dontfeartheripper 0.0.5

Highlights
----------

- Added dftr stats command
- Added library statistics reporting
- Added category counters
- Added container statistics
- Added metadata coverage reporting
- Added rename candidate statistics

Examples
--------

Scan:

    dftr scan /music

Diagnose:

    dftr doctor /music

Statistics:

    dftr stats /music

Rename preview:

    dftr fix /music

Rename:

    dftr fix /music --yes

Rollback:

    dftr undo
