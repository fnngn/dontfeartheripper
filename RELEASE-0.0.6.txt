dontfeartheripper 0.0.6

Highlights
----------

- Added dftr stats command
- Added JSON statistics output
- Added stable statistics schema (v1)
- Added reusable statistics engine
- Added statistics test suite

Examples
--------

Human readable output:

    dftr stats /music

JSON output:

    dftr stats /music --json

JSON + jq:

    dftr stats /music --json | jq .

Other commands:

    dftr doctor /music
    dftr fix /music
    dftr fix /music --yes
    dftr undo
