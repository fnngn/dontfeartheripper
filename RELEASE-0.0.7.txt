dontfeartheripper 0.0.7

Highlights
----------

- Added doctor --json
- Added machine-readable diagnostics
- Added versioned doctor JSON schema
- Added structured warning reporting
- Added structured informational reporting

Examples
--------

Human readable diagnostics:

    dftr doctor /music

JSON diagnostics:

    dftr doctor /music --json

Human readable statistics:

    dftr stats /music

JSON statistics:

    dftr stats /music --json

Rename preview:

    dftr fix /music

Rename:

    dftr fix /music --yes

Rollback:

    dftr undo

Doctor JSON Schema
------------------

{
  "schema_version": 1,
  "warnings": [],
  "info": []
}
